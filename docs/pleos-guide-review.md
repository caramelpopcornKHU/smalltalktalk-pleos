## ✅ 이미 맞춘 것

- 차량 하드웨어 직접 접근 없음, 모바일 전용 API(전화·SMS·센서·캘린더·주소록) 안 씀
- 안전 영역: 시스템 바·컷아웃을 피해 그림(전체화면 헤더 가림 수정)
- 창 크기·방향이 바뀌어도 다시 만들지 않고 반응형으로 다시 그림, 대화는 ViewModel이라 유지
- 큰 터치 영역(버튼 72~88dp), 큰 글자, 드롭다운·다단 메뉴 없음
- 주행 중 키보드 대신 음성(이름 입력), 글 대신 소리(코칭·습관 리포트·아침 브리핑), 영상 없음
- 통신 HTTPS, 토큰은 Authorization 헤더로만, 앱에는 publishable 키만(비밀 키 하드코딩 없음)
- 오디오 포커스 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK` + `USAGE_ASSISTANT`(가이드의 VOICE_COMMAND 컨텍스트)
- 개인정보 최소: 대화 원문 저장 안 함(습관은 태그와 12자 이하 표현만), 이름은 본인만
- minSdk 28, Gradle 8+, Kotlin, 에뮬레이터 API 34 조건 충족

### PC방에서 추가로 볼 것 (이번 수정)

- Virtual Console에서 기어 D·속도 올리기 → 앱이 막히지 않고 "주행 중" 화면(큰 버튼·소리만)으로 바뀌는지, P로 돌아오면 목록·코칭이 다시 보이는지
- 대화 중 다른 앱을 전체화면으로 → 마이크 표시가 꺼지고, 돌아오면 코칭 화면이 나오는지
- 대화 중 내비 안내 같은 다른 소리가 나면 상대 목소리가 멈추거나 작아지는지
- 앱을 업데이트 설치해도 이름·습관 기록이 그대로인지(토큰 암호화 전환 확인)
- 와이파이를 끈 채 앱을 켜면 저녁 연습 목록·오늘 아침 카드가 보이는지
- 상대 첫 마디의 첫 음절이 잘리는지 (8번 결정용)
